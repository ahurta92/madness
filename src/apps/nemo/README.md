# NEMO workflow data

Run this engine through `madqc --wf=nemo`. The duplicate `nemo`
main and executable target are retired; this directory retains historical
inputs and notes. Numerical algorithms remain in `src/madness/chem`.

Use the [madqc guide](../madqc/README.md) and
[curated QC decks](../../examples/qc/README.md) for current input examples.
The [test migration index](../../../docs/design/madqc-driver-test-migration.md)
distinguishes retained scientific coverage from remaining release gaps.
